# Nature Sounds - Download Instructions

This folder contains peaceful nature sounds for Islamic meditation and relaxation.

## Free High-Quality Nature Sound Resources

Download these sounds from the following **free, royalty-free** sources:

### 1. Freesound.org
- **Website**: https://freesound.org/
- **License**: Creative Commons (CC0, CC BY)
- **Recommended Searches**:
  - "birds chirping peaceful"
  - "ocean waves calm"
  - "soft rain nature"
  - "forest ambience"
  - "water stream flowing"
  - "gentle wind breeze"

### 2. ZapSplat
- **Website**: https://www.zapsplat.com/sound-effect-categories/nature/
- **License**: Free for commercial use
- **Categories**:
  - Nature & Animals

  - Water

### 3. Pixabay
- **Website**: https://pixabay.com/sound-effects/search/nature/
- **License**: Pixabay License (Free for commercial use)
- **High-Quality Nature Sounds**

### 4. Free Music Archive
- **Website**: https://freemusicarchive.org/
- **Search**: "nature ambient" or "field recording"
- **License**: Various CC licenses

### 5. YouTube Audio Library
- **Website**: https://www.youtube.com/audiolibrary
- **Filter**: Sound effects → Nature
- **License**: Free to use

## Required Files

Download and place these files in this folder (`assets/audio/nature/`):

1. **birds-chirping.mp3** - Peaceful bird sounds (Islamic: mentioned in Quran)
2. **ocean-waves.mp3** - Calming ocean waves
3. **rain-soft.mp3** - Gentle rain for meditation
4. **forest-ambience.mp3** - Forest atmosphere
5. **water-stream.mp3** - Flowing water sounds
6. **wind-breeze.mp3** - Gentle wind sounds

## Islamic Context

These nature sounds are mentioned or referenced in Islamic texts:
- **Birds**: Frequently mentioned in the Quran (24:41, 67:19)
- **Rain**: Allah's blessing (Quran 24:43, 30:24)
- **Water**: Source of life (Quran 21:30)
- **Mountains/Nature**: Signs of Allah's creation (Quran 88:17-20)

## File Format Guidelines

- **Format**: MP3 or WAV
- **Quality**: 192kbps or higher
- **Duration**: 2-10 minutes (will loop)
- **File Size**: Keep under 5MB for app performance

## Downloading Steps

1. Visit one of the free resources above
2. Search for the nature sound you want
3. Download in MP3 format
4. Rename the file to match the required filename
5. Place in `assets/audio/nature/` folder
6. Run `flutter pub get` to update assets

## Attribution (if required)

If using CC BY license, add attribution in your app:
