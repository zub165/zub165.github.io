## Instructions

1. Download each sound file from the sources above
2. Rename files to match the exact names listed above
3. Save all files to: `assets/audio/nature/`
4. Ensure files are in MP3 format
5. Keep file sizes under 5MB each for best performance
6. After adding files, run: `flutter pub get`
7. Hot restart the app

## File Naming Convention

All files must match exactly:
- `eagle-call.mp3` (not `eagle_call.mp3` or `Eagle-Call.mp3`)
- `lion-roar.mp3`
- `birds-chirping.mp3`
- etc.

## Testing

After downloading:
1. Run `flutter clean`
2. Run `flutter pub get`
3. Run `flutter run`
4. Navigate to Animals, Water, or Forest tabs
5. Select sounds and play

## Notes

- All sounds should be loopable (seamless loops work best)
- Recommended quality: 192kbps MP3 or higher
- Duration: 10-30 seconds (will loop automatically)
- Ensure files are properly formatted (MP3, 44.1kHz sample rate recommended)
